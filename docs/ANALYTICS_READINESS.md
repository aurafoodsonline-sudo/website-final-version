# Analytics Readiness

Operational analytics are provided from application data:

- Supplier payable and advance balances.
- Stock value.
- Ledger row counts.
- Report-backed near-expiry, expired stock, yield, wastage, packing, supplier aging, and stock-value analytics.

Third-party analytics:

- Disabled by default.
- `ANALYTICS_ID` is an optional placeholder for a future public-facing page.
- Do not enable third-party analytics without a privacy notice, consent review, and explicit environment variable.

No invasive or hidden analytics scripts are included in this release candidate.
